# 冷门宇宙 · 免费每日数据雷达

这个公开仓库只保存“冷门宇宙”网站的每日前沿数据和自动更新程序，不包含账号、密钥或私人数据。

## 它如何更新

- 每天北京时间 **00:17** 由 GitHub Actions 自动运行。
- 直接读取 NASA、NIST、NIH PubMed、世界银行开放数据与斯坦福哲学百科的公开数据或订阅源。
- 在历史记录中去重，按五个话题轮换选择当天的主信号，并为每个话题保留一条最新动态。
- 只整理官方标题、摘要与原文链接；**不调用大模型，不使用付费 API，也不自动编造中文结论**。
- 某个来源暂时离线时，沿用该话题上一次成功内容；全部失败时不覆盖已有数据。

## 文件

- `daily.json`：网站读取的今日数据。
- `history.json`：最近展示记录，用于去重。
- `scripts/update-daily.mjs`：零依赖抓取与筛选脚本。
- `.github/workflows/update-daily.yml`：每日定时任务，也支持手动运行。

内容版权与使用条件归各原始发布机构所有；本仓库只保存标题、短摘要和指向原文的链接。
